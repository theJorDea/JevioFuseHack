Public historical [fix 8227ad6](https://github.com/theJorDea/JevioFuseHack/commit/8227ad62f40f53f4d1bd4f071a929a4e6a25c602), parent `56b4887763101a339ec2a6771542ec5940c441b9`. Before the fix the overlay became visible but focus did not move to its list. This case tests terminal focus ownership, distinct from restoring web chat state after reload.

The snapshots are verbatim method excerpts from `src/interactive-tui.ts`, blob IDs `14b6f709a8272d7fdf9e69daf9af544e4ad29a30` (base) and `0d900f8723a7384beb7d916f938cd0e388a9df34` (gold). Reconstruction from the UTF-8 Git blob: slice from the first `  private async showSessionPicker(` up to but excluding `\n  private async resumeFromPicker(`. Do not trim or normalize. `case.mjs` pins those excerpt bytes and the probe using SHA-256. Expose only the base method and task to a model.

Probe: wrap the excerpt in a class for Node type stripping and run the trusted method with small terminal-component doubles preserving object identity and focus. A populated picker must focus the selectable list, cancel must close it and restore the editor. Empty history must keep the editor focused, no overlay displayed, and show the existing empty-state notice. This is not a real-terminal rendering test. No external packages, model output or network. `node:vm` here is for injecting mocks into trusted historical code only, not an execution boundary for candidates. In each snapshot cwd run `node PATH/TO/probe.mjs target` and `control` separately. Verified base FAIL/PASS and gold PASS/PASS on Node 24.14.1.
